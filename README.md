# Fortune Cookie Wisdom for Developers

One original fortune-cookie line for a software developer. `main.ts` writes the line to `entry.txt`, enforcing the gates — exactly one line, non-empty, at most 120 characters, no leading or trailing space, and no control characters — then reads the file back and verifies the bytes match.

> "Legacy code is not a mess you inherited; it is a letter from someone who was as tired as you are now."

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/u-gentle-koala-fortune-out node main.ts
```
